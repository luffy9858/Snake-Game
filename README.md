A classic Snake Game built using Python and Pygame-CE, inspired by the old Nokia phone Snake game.
This is my first game development project, built as part of my journey into learning Python and programming.

Features so far: 
1. Classic snake movement and gameplay.
2. Food spawning and collision detection.
3. Snake grows whenever it eats an apple.
4. Score tracking.
5. Increasing difficulty as your score increases.
6. Game over screen with restart functionality.
7. Added Obstacles (5th Nov,2026)
8. Added AI Obstacles that recognize user pattern (6th Nov,2026)
9. Added Brutuality in AI (New - 10th Nov,2026)

Controls:
1. WSAD - For movements
2. Esc - To exit game

Requirements:
1. Python 3.14+ (Don't know if it will work on previous one or not, but I made it on this version tho)
2. Pygame-CE (use "pip install Pygame-CE")
